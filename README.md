# Awesome Agent Skills BR

Uma lista curada, em português, de Agent Skills para Claude, Codex e outros agentes de IA — com comando de instalação e link para a ficha completa de cada skill.

Mantida a partir do catálogo [atalhos.ia.br](https://atalhos.ia.br) (1.000 skills, 455 fontes).

- [find-skills](https://atalhos.ia.br/skills/agentspace-so/skills/find-skills) — busca de skills em múltiplos registros (agentspace-so/skills)
- [seo-audit](https://atalhos.ia.br/skills/coreyhaines31/marketingskills/seo-audit) — auditoria SEO on-page e técnica (coreyhaines31/marketingskills)
- [supabase](https://atalhos.ia.br/skills/supabase/agent-skills/supabase) — trabalhar com Supabase a partir do agente (supabase/agent-skills)
- [test-driven-development](https://atalhos.ia.br/skills/obra/superpowers/test-driven-development) — fluxo TDD para agentes (obra/superpowers)
- [pptx](https://atalhos.ia.br/skills/anthropics/skills/pptx) — criar e editar apresentações (anthropics/skills)

## Como sugerir uma skill

Abra uma issue com o link do repositório da skill. Skills entram primeiro no catálogo do atalhos e aparecem aqui na curadoria semanal.
